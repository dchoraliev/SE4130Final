Required Hardware:
-1 x STM32F413H–Discovery Board
-1 x USB Cable​
-1 x Breadboard​
-1 x Joystick Module​
-1 x Button ​
-6 x Wires

Harware Assembly Steps:
1:Connecting the button
1.1:Place "Button" component firmly into center of the breadboard
1.2:Connect front-right button pin to D2 port on STM32 board via wire
1.3:Connect back-left button pin to GND port on STM32 board via wire
2:Connecting the joystick
2.1:Place "Joystick" component near breadboard
2.2:Connect joystick GND pin to GND port on STM32 board via wire
2.3:Connect joystick +5V pin to 3V3 port on STM32board via wire
2.4:Connect joystick VRx pin to A0 port on STM32board via wire
2.5:Connect joystick VRy pin to A1 port on STM32board via wire
3:Connect STM32F413H–Discovery Board to computer via USB Cable
4:You're ready to play
